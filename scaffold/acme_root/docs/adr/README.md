# Decisions

Each file here records one decision that constrains future work: its
context, the decision, and its consequences, with a status of one date.
Code and prose cite a decision by its number, and the number never
changes. A decision says what holds: it is rewritten in place when it
changes, and removed when it constrains nothing.

The scaffold's decisions are numbered below 1000. A copy numbers its
own from 1001, so a later release of the scaffold never takes a number
the copy uses.

A copy never edits a decision the scaffold gave, not even to add a row.
What it extends or changes goes in a decision of its own, which cites
the scaffold's by number and title, such as "ADR 0002, Technology
choices as adopted". Each later release of the scaffold then rewrites
its own with no conflict.

[The architecture spec](../../specs/architecture.md) pins the guideline
and links the decisions that depart from it.
